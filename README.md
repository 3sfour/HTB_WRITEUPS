# Hack The Box Writeups

My personal writeups for Hack The Box content, organized by type.

> **Spoiler policy:** Only retired content is published here. Active Machines and Challenges are never written up publicly, and flags/passwords are always redacted.

## Structure

| Folder | HTB content type | Publish publicly? |
|---|---|---|
| [`machines/`](machines/) | Machines (Easy / Medium / Hard / Insane, Linux / Windows / other) | Retired only |
| [`challenges/`](challenges/) | Challenges (web, crypto, reversing, pwn, forensics, hardware, misc) | Retired only |
| [`sherlocks/`](sherlocks/) | Sherlocks (blue team / DFIR investigations) | Retired only |
| [`starting-point/`](starting-point/) | Starting Point tiers | Yes |
| [`fortresses-endgames/`](fortresses-endgames/) | Fortresses / Endgames (if still available) | Retired only |
| [`pro-labs/`](pro-labs/) | Pro Labs (multi-machine red team networks) | Keep private (study notes) |
| [`cloud-labs/`](cloud-labs/) | Cloud Labs (AWS / Azure / GCP) | Keep private (study notes) |
| [`templates/`](templates/) | One writeup template per content type | n/a |
| [`assets/`](assets/) | Shared images and diagrams | n/a |

## How to add a writeup

1. Copy the matching template from `templates/` into the right folder.
2. Name it after the box, e.g. `machines/linux/easy/boxname.md` or `challenges/web/challengename.md`.
3. Fill it in from your own notes and tool output.
4. Redact all flags, hashes of flags, and live credentials.
5. Add a row to that folder's `README.md` index.

## Index

Each folder has its own `README.md` with a table of completed writeups.
